    SETUP

    ما يلزم لتشغيل الميزات العامة

    1. Supabase

    أنشئ مشروعًا ثم شغّل ملف community-database.sql في SQL Editor.

    2. site-config.js

    ضع Project URL وAnon key فقط، ثم غيّر communityEnabled إلى true. لا تضع Service Role Key.

    3. Email confirmation

    اضبط رابط الموقع في Authentication URL Configuration واختبر تأكيد البريد.

    4. Moderation

    راجع الرسائل من Supabase وأضف Turnstile أو Rate Limiting قبل فتح التسجيل على نطاق واسع.
