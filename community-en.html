    SETUP

    Required setup for public features

    1. Supabase

    Create a project, then run community-database.sql in the SQL editor.

    2. site-config.js

    Add only the Project URL and anon key, then set communityEnabled to true. Never add a service-role key.

    3. Email confirmation

    Set the site URL in Authentication URL Configuration and test email confirmation.

    4. Moderation

    Review messages in Supabase and add Turnstile or rate limiting before broad public registration.
