طريقة تنظيف Windows من الملفات غير المهمة

دليل عملي وآمن نسبيًا لتنظيف ملفات Windows المؤقتة مع الأوامر وطريقة تنفيذها.

أنشئ نقطة استعادة، أغلق البرامج، واقرأ مستوى الخطورة قبل التنفيذ. لا تستخدم أدوات الحذف الجماعي أو سكربتات مجهولة.
1أنشئ نقطة استعادة
2افتح Terminal بالطريقة المطلوبة
3انسخ الأمر والصقه
4راجع النتيجة قبل المتابعة
01 إعدادات Windows منخفض الخطورة

Storage Sense والملفات المؤقتة

راجع تصنيفات الملفات المؤقتة واحذف العناصر التي تعرفها فقط. اترك التنزيلات دون تحديد إلا إذا كنت تقصد حذفها.

الأمر أو المسار 
Settings → System → Storage → Temporary files
طريقة التنفيذ افتح الإعدادات ثم النظام ثم التخزين ثم الملفات المؤقتة. راجع القائمة واضغط إزالة الملفات.
02 نافذة Run أو CMD منخفض الخطورة

فتح أداة تنظيف القرص

تشغيل واجهة Disk Cleanup المدمجة واختيار تصنيفات الملفات المؤقتة أو ملفات النظام.

الأمر أو المسار 
cleanmgr
طريقة التنفيذ اضغط Win + R، اكتب cleanmgr، اضغط Enter، اختر القرص C: ثم راجع التصنيفات.
03 CMD كمسؤول راجع قبل التنفيذ

إعداد خيارات تنظيف قابلة لإعادة الاستخدام

فتح نافذة خيارات موسعة وحفظ تصنيفات التنظيف المختارة ضمن الملف رقم 1.

الأمر أو المسار 
cleanmgr /sageset:1
طريقة التنفيذ افتح Terminal كمسؤول، الصق الأمر، اختر التصنيفات بعناية ثم اضغط موافق.
04 CMD كمسؤول راجع قبل التنفيذ

تشغيل ملف تنظيف القرص المحفوظ

تشغيل تصنيفات التنظيف التي حُفظت مسبقًا في ملف sageset رقم 1.

الأمر أو المسار 
cleanmgr /sagerun:1
طريقة التنفيذ شغّل هذا الأمر بعد إكمال cleanmgr /sageset:1 ومراجعة التصنيفات المختارة.
05 Terminal كمسؤول منخفض الخطورة

تحليل مخزن مكونات Windows

تحليل مخزن مكونات WinSxS وعرض ما إذا كان تنظيف المكونات موصى به.

الأمر أو المسار 
DISM /Online /Cleanup-Image /AnalyzeComponentStore
طريقة التنفيذ افتح Windows Terminal كمسؤول، الصق الأمر وانتظر حتى يكتمل التقرير.
06 Terminal كمسؤول راجع قبل التنفيذ

تنظيف مكونات Windows المستبدلة

إزالة إصدارات المكونات القديمة التي لم يعد Windows يحتاجها للصيانة العادية.

الأمر أو المسار 
DISM /Online /Cleanup-Image /StartComponentCleanup
طريقة التنفيذ أغلق برامج التثبيت المفتوحة، افتح Terminal كمسؤول، شغّل الأمر واتركه حتى يكتمل دون مقاطعة.
07 PowerShell راجع قبل التنفيذ

تنظيف مجلد الملفات المؤقتة للمستخدم الحالي

محاولة حذف الملفات من مجلد المستخدم المؤقت. يتم تجاوز الملفات المستخدمة حاليًا.

الأمر أو المسار 
Get-ChildItem -Path $env:TEMP -Force -ErrorAction SilentlyContinue | Remove-Item -Recurse -Force -ErrorAction SilentlyContinue
طريقة التنفيذ أغلق البرامج أولًا، افتح PowerShell، الصق الأمر واضغط Enter. قد تبقى بعض الملفات لأنها قيد الاستخدام.
08 PowerShell قد يسبب حذفًا أو انقطاعًا

إفراغ سلة المحذوفات

إفراغ سلة المحذوفات نهائيًا للأقراص المتاحة.

الأمر أو المسار 
Clear-RecycleBin -Force
طريقة التنفيذ راجع سلة المحذوفات أولًا. بعدها افتح PowerShell والصق الأمر واضغط Enter.
09 PowerShell منخفض الخطورة

مراجعة الملفات الكبيرة داخل التنزيلات

عرض أكبر 20 ملفًا داخل مجلد التنزيلات دون حذف أي شيء.

الأمر أو المسار 
Get-ChildItem $HOME\Downloads -File -Recurse -ErrorAction SilentlyContinue | Sort-Object Length -Descending | Select-Object -First 20 Name, Directory, @{Name='SizeGB';Expression={[math]::Round($_.Length/1GB,2)}}
طريقة التنفيذ شغّل الأمر في PowerShell، راجع المسارات ثم احذف يدويًا الملفات التي لا تحتاجها فقط.
10 CMD كمسؤول قد يسبب حذفًا أو انقطاعًا

تعطيل السبات لحذف hiberfil.sys

تعطيل السبات وحذف ملفه المحجوز. قد يؤدي ذلك أيضًا إلى تعطيل Fast Startup في كثير من الأجهزة.

الأمر أو المسار 
powercfg /hibernate off
طريقة التنفيذ استخدمه فقط إذا كنت لا تحتاج وضع السبات أو Fast Startup. لإعادته لاحقًا شغّل powercfg /hibernate on.
ما الذي لا أنصح به؟

لا تحذف مجلدات Windows أو WinSxS يدويًا، ولا تمسح سجلات الأحداث، ولا تستخدم أوامر حذف Shadow Copies بهدف توفير المساحة.
