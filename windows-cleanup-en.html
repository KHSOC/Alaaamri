How to Clean Unnecessary Windows Files

A practical, safety-focused Windows cleanup guide with commands and execution steps.

Create a restore point, close applications, and read each risk label before running commands. Avoid unknown debloat scripts and bulk deletion tools.
1Create a restore point
2Open the required terminal
3Copy and paste the command
4Review the result before continuing
01 Windows Settings Low risk

Storage Sense and Temporary Files

Review temporary-file categories and remove only the items you recognize. Keep Downloads unchecked unless you intentionally want to delete those files.

Command or path 
Settings → System → Storage → Temporary files
How to run it Open Settings, choose System, then Storage, then Temporary files. Review the list and select Remove files.
02 Run or CMD Low risk

Open Disk Cleanup

Launch the built-in Disk Cleanup interface and choose temporary or system-file categories.

Command or path 
cleanmgr
How to run it Press Win + R, type cleanmgr, press Enter, select drive C:, then review the categories.
03 CMD as Administrator Review first

Configure reusable Disk Cleanup options

Open an extended selection window and save the chosen cleanup categories under profile number 1.

Command or path 
cleanmgr /sageset:1
How to run it Open Terminal as Administrator, paste the command, choose categories carefully, then press OK.
04 CMD as Administrator Review first

Run the saved Disk Cleanup profile

Run the cleanup categories previously saved with sageset profile 1.

Command or path 
cleanmgr /sagerun:1
How to run it Run this only after completing cleanmgr /sageset:1 and reviewing its selected categories.
05 Terminal as Administrator Low risk

Analyze the Windows component store

Analyze the WinSxS component store and report whether component cleanup is recommended.

Command or path 
DISM /Online /Cleanup-Image /AnalyzeComponentStore
How to run it Open Windows Terminal as Administrator, paste the command, and wait for the report to complete.
06 Terminal as Administrator Review first

Clean superseded Windows components

Remove superseded component versions that Windows no longer needs for normal servicing.

Command or path 
DISM /Online /Cleanup-Image /StartComponentCleanup
How to run it Close running installers, open Terminal as Administrator, run the command, and allow it to finish without interruption.
07 PowerShell Review first

Clear the current user's temporary folder

Attempt to remove files from the current user's temporary folder. Files in use are skipped.

Command or path 
Get-ChildItem -Path $env:TEMP -Force -ErrorAction SilentlyContinue | Remove-Item -Recurse -Force -ErrorAction SilentlyContinue
How to run it Close applications first, open PowerShell, paste the command, and press Enter. Some files may remain because they are in use.
08 PowerShell Potentially destructive

Empty the Recycle Bin

Permanently empty the Recycle Bin for available drives.

Command or path 
Clear-RecycleBin -Force
How to run it Review the Recycle Bin first. Then open PowerShell, paste the command, and press Enter.
09 PowerShell Low risk

Review large files in Downloads

List the 20 largest files in Downloads without deleting anything.

Command or path 
Get-ChildItem $HOME\Downloads -File -Recurse -ErrorAction SilentlyContinue | Sort-Object Length -Descending | Select-Object -First 20 Name, Directory, @{Name='SizeGB';Expression={[math]::Round($_.Length/1GB,2)}}
How to run it Run in PowerShell, review the paths, then manually delete only files you no longer need.
10 CMD as Administrator Potentially destructive

Disable hibernation to remove hiberfil.sys

Disable hibernation and remove its reserved file. This also disables Fast Startup on many systems.

Command or path 
powercfg /hibernate off
How to run it Use only when you do not need Hibernate or Fast Startup. To restore it later, run powercfg /hibernate on.
What should you avoid?

Do not manually delete Windows or WinSxS folders, erase event logs, or delete shadow copies merely to save space.
